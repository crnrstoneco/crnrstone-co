Show the formulas
  • Height = Run × tan (Seat)
  • Rafter length = Run ÷ cos (Seat)
  • Hip / Valley run = Run × 1.414
  • Hip / Valley length = √ (Hip run² + Height²)
  • Hip / Valley seat angle = tan⁻¹ (Height ÷ Hip run)
  • Plumb angle = 90° − Seat
  • Creeper reduction = Rafter spacing ÷ cos (Seat)
  • Creeper length = Rafter length − (Creeper number × Creeper reduction)

These assume a square-cornered roof with the same pitch on both sides, so the hip sits at 45° in plan. Rafter run is the half span for the main roof and the eave width for the eave.
