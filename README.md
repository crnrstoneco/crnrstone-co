# crnrstone-co

Building strong foundations for trades. Learning tools, calculators and safety documents for apprentices, educators and tradies.

Live site (test address): https://crnrstoneco.github.io/crnrstone-co/

Not here yet: the Vault (SDS and install guides). It needs user accounts and storage before it can work on this site.

## How the site works

- Every page is one self-contained HTML file. No build step: what's in the folder is what's served.
- Hosted free on GitHub Pages from the `main` branch.
- The shared look (colours, fonts, grid, Night/Day toggle) is set out in the Design Brief, kept in the Crnrstone-co Claude project.
- Anything a user types (JSAs, business profile, calculator history) saves in their own browser on that device. Nothing is stored on a server yet.
